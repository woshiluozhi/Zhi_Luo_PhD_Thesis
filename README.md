# PhD Thesis

This repository contains the final PDF of my PhD dissertation submitted to Chongqing University.

**Title:** Observational Signatures of Black Hole Shadows and Black Hole Phase Transitions in Different Spacetime Backgrounds
**Author:** Zhi Luo
**Degree:** Doctor of Philosophy in Physics
**Supervisor:** Prof. Jin Li
**Institution:** Chongqing University
**Year:** 2025

## Description

This dissertation studies observational signatures of black hole shadows, holographic Einstein rings, wormhole images, and black hole phase transitions in different spacetime backgrounds.
